# Visual judgment, not a beauty score

For each axis, record **improved / unchanged / worse / uncertain**, one visible observation, and the screenshots/region supporting it. Judge against the product's audience and task, not personal preference alone.

| Axis | Useful question | Common false win |
|---|---|---|
| Task hierarchy | Is the intended next action easier to locate? | Making every action loud; hiding alternatives |
| Grouping and rhythm | Are related pieces grouped and unrelated groups separated? | Applying equal spacing everywhere |
| Type and reading | Are levels distinct, lines comfortable, essential text readable? | Replacing fonts without fixing scale or wraps |
| Responsive integrity | Does the hierarchy and content survive narrow width? | Hiding content, clipping, or desktop-only proof |
| Product continuity | Does this still feel like the same product? | A trendy replacement template or new copy |

First assess full-page composition, then inspect the changed region at native scale. Record regressions even if a different area improved. For a stronger evaluation, ask an independent reviewer to compare unlabeled A/B screenshots using the same task brief, allow ties, and report their rationale. One fixture is a demonstration, not evidence of general effectiveness. Before/after code and test outputs must remain inspectable.
